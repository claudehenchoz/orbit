# ORBIT 0.7.0

**New ways to shape a loop, with the original Event Tape workflow intact.**

ORBIT 0.7.0 adds oscillator-source CLOUD, sound-owned user macros, faster
envelope/modulation editing and immediate preset browsing to the FM-1's
three-synth-plus-drum workflow. It also integrates the functional SLOOP 2.6
improvements. [Product introduction](../../README.md) · [User guide](../../GUIDE.md)

## Musical changes

- **CLOUD:** an original oscillator-source granular engine with WAVE, SIZE,
  DENS, SPRD, DTUN, CHRP, STCK and TONE. Eight appended sounds: CIRRUS,
  SILVER MIST, GLASS RAIN, EMBER, SKY FIFTHS, COMET TAIL, DUST PULSE and
  LOW STRATUS. GRAIN remains the separate sample-source granular engine.
- **User macros:** four synth-sound assignments on MACROS; their mapped
  values on the adjacent PERFORM page through EDIT/SELECT. USER sounds,
  project/section snapshots, autosave and backups retain the map.
  HOME remains Event Tape / Visualizer with its original Tape knobs.
- **ENV/LFO travel:** wide numeric ranges use larger detents; named choices
  remain discrete. An instant PRESETS list on Tape/Mixer auditions each
  sound, then dismisses on edits/navigation or timeout.
- **SLOOP 2.6 effects:** eight INSERT types plus dry/wet per track, 27
  punch-in effects including eleven black-key effects, REV/ECHO THROW,
  1/4D delay, live drum mutes and a separate TEXTURE bed.
- **Modulation and sequencing:** ENV SYNC, LFO SYNC/TRIG/POL, ANALOG LP/BP/HP
  filter type, note LEN, step velocity, MIDI keyboard step entry, project
  erase and the latched-arp correction.
- **MIDI:** per-track channels, single-channel input mode, sustain, pitch
  bend, Program Change and 16 persistent CC-learn slots. See
  [controller instructions](../MIDI-CONTROL.md), including MiniLab routing
  and absolute-CC requirements.
- **Output and editing paths:** look-ahead limiting, filter-state seeding,
  sound-change fades, SYN kick ramp and editor same-value resend. The
  web editor transports maps and signed16 values with protocol **12**,
  migrates older ORBIT data and preflights full backups.
- **Installation:** a product introduction and native screen captures lead
  the new Web MIDI installer. It automatically validates the latest stable
  release before Connect, then separately preflights Install. CLI fallback
  and reproducible site generation are documented.

The default bank is **17 engines / 189 factory sounds**. Existing engine
IDs and factory order are preserved; CLOUD appends at ID 16. CLUSTER
remains ID 15 with its original 16 raw presets. Optional SLICE changes
the subsequent numeric IDs and is not part of the default build.

The three synth parts share **eight global voices**. CLUSTER is at most
four per part, CLOUD at most three; engine mode, other parts and CPU
shedding can reduce sounding voices. MONO/LEGATO are intentionally one
voice. CLUSTER's bit-identical arithmetic optimization and the new limiter
address measured cost/headroom concerns, not a proven physical crackle fix.

## Install and back up first

The release target is **0.7.0** and install identity **FM-1_900**. Use the
default build; **do not pass --release**, which changes product identity.
The browser installer address is
[https://dspaudio.github.io/orbit/](https://dspaudio.github.io/orbit/).
Check its displayed package version before writing.

Open the site in Chrome/Edge, connect with a USB data cable,
grant SysEx through Connect and use Install only after package/device checks.
Keep USB and power connected through reboot. For a checked local package:

```sh
python3 tools/fm1_install.py --info
python3 tools/fm1_install.py build/orbit.fwsc
```

Dependencies, target build and local site instructions: [BUILDING.md](../../BUILDING.md).
No package hash, image size or target budget is asserted in these notes;
final measurements belong to the [validation record](../VALIDATION.md).

**BACKUP before updating.** Stop and export the editor's full Projects /
Backup file. Keep the pre-update backup separately from 0.7.0 backups.

| Data | 0.7.0 contract |
| --- | --- |
| Projects/working autosave | New **ORP7**, 3840-byte object, preserving sound values, new controls and four macro IDs per track |
| USER preset banks | New **OPB2** with maps; frozen UPB1 reader for older ORBIT banks |
| Legacy ORBIT projects | Frozen FUN1-FUN5 import with parameter-count migration and signed16 values retained |
| Raw SLOOP 2.6 FUN6 | Rejected; a different registry/layout is not interchangeable |
| MIDI learn/routing | Device settings, separate from sound maps, included in full backup |
| Downgrade | Old firmware cannot read ORP7/OPB2; restore the matching pre-update backup on matching old firmware |

An older autosave can overwrite unreadable new work. Do not assume new MIDI
settings or SYN kits survive an old settings reader. Engine/format identity
must be checked; a legacy magic alone does not establish SLOOP-to-ORBIT
compatibility. [Backup and recovery guide](../../GUIDE.md#backup-updates-and-downgrades).

## Evidence and limits

Focused host evidence covers the port's storage migration, effects/modulation,
MIDI settings and macro persistence, CLOUD/CLUSTER coexistence and the
corrected Tape/PERFORM navigation. Native preview and simulated installer
checks are software evidence, not hardware tests. Final integrated regression,
package and target measurements are recorded separately in
[VALIDATION.md](../VALIDATION.md).

The current CLUSTER health probe rendered 624 conditions, including 576
full mixes and 48 isolated-track conditions. Requested POLY voices remained
present in the tested full-mix cases and endpoint clipping counts were zero.
This does not prove target ISR deadlines, DMA behavior or subjective quality.
[CLUSTER scope](../OP1-CLUSTER.md).

Physical **0.6.0** installation and a short 48 kHz USB recording on
**2026-10-10** remain historical. **0.7.0 hardware timing, power-loss tests
and resolution of the reported physical crackle are not yet verified.**
The 0.7.0 package was installed on an FM-1: transfer reached 100%, automatic
reboot completed, and actual INFO reported `FELUCCA ORBIT 0.7.0` with protocol
12, 17 engines and 45 globals; PING passed. Complete pre/post backups passed
CRC checks, with the working project's musical data preserved through the
FUN5-to-ORP7 conversion. This is installation evidence, not an audio test.
