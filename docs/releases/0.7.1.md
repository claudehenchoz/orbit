# ORBIT 0.7.1

**A clearer drum grid, more precise controls and a smaller firmware image.**

ORBIT 0.7.1 refines the FM-1 workflow introduced in 0.7.0 without changing
the sound engines, factory bank, project formats or editor protocol.
[Product introduction](../../README.md) · [User guide](../../GUIDE.md)

## Changes

- **Drum matrix:** GRID shows all sixteen instrument rows against sixteen
  time columns, with compact voice labels, four-step groups, selected row,
  cursor, playhead, levels and ratchets. Eleven black keys select voices
  silently; white keys toggle the selected voice's steps. OCT-/OCT+ change
  16-step pages, and KNOB 1 still reaches all sixteen voices. KIT keeps its
  live-pad behavior.
- **Recording from GRID:** REC/free-take screens route keys to live recording
  rather than editing hidden grid steps. Voice selection precedes simultaneous
  step presses, repeated toggles stay separate, and removing the last hit clears
  its nudge, fill condition and locks consistently.
- **Precise ENV/LFO turns:** slow turns move one numeric value index per detent;
  fast turns retain accelerated travel. Named divisions and choices remain
  discrete.
- **Step automation:** while playback and REC are active on the selected
  track, supported sound-page knobs write parameter locks on the current
  step, including mapped PERFORM controls. This shares the existing 24-lock
  table; it is discrete step automation, not continuous motion recording.
  Global, pattern, assignment and live Mixer/KIT controls are excluded.
  Recording headers distinguish live-only controls with NO AUTO.
- **Tape shortcuts:** hold SEL with OCT- to COPY/LIFT and with OCT+ to DROP.
  Plain OCT buttons retain synth octave control, including the two-button
  reset. The idle hint displays the shortcuts and follows COPY/LIFT.
- **Safer pattern edits:** SHIFT moves notes/hits, nudges, fill and locks
  together. LENGTH x2 copies their metadata and refuses lock-capacity overflow
  without modifying the pattern or previous Undo. Synth and drum DROP support
  Undo/Redo; failed DROP and failed automation insertion preserve prior Undo.
- **Display fixes:** the fourth SYSTEM row fits above the screen edge, long
  SONG entries leave room for their labels/play markers, and FX headers
  distinguish TRACK from ALL settings.
- **Lossless size reductions:** binary font packing and shared glyph storage
  retain the rendered pixels, unused code/data sections are discarded, and
  screen transfers share their argument setup. Audio samples and factory
  sounds are retained. Package files still pad the fixed application slot,
  so a smaller app does not imply a smaller download.

## Compatibility and installation

The default build remains **17 engines / 189 factory sounds**, editor
protocol **12**, **ORP7** projects and **OPB2** USER preset banks. Existing
engine IDs, factory order and the **FM-1_900** install identity are unchanged.
0.7.0 and 0.7.1 use the same storage formats. Firmware older than 0.7.0
cannot read these formats; raw SLOOP FUN6 remains unsupported.

**Back up before updating.** Stop playback and export a full backup from
the editor. Install through [the Web MIDI installer](https://dspaudio.github.io/orbit/)
in Chrome/Edge, checking that it displays 0.7.1 before writing. The local
fallback is `python3 tools/fm1_install.py build/orbit.fwsc`.
For a source build, use the default build command, not `--release`.
See [BUILDING.md](../../BUILDING.md).

## Verification and limits

Package measurements, hashes and test results belong to the
[validation record](../VALIDATION.md). Host audio, display, storage and
simulated update checks are software evidence. Static pi32v2 cost checks
are not actual cycle or ISR-deadline measurements.

**0.7.1 has not been installed or tested on an FM-1.** The earlier 0.7.0
installation/version/PING checks and 0.6.0 USB recording are historical,
not validation of this release on hardware. Physical timing, crackle
resolution, power-loss recovery and controller behavior remain unverified.
